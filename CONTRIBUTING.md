# Contributing to Cataquí Mobile

Thank you for helping make nearby work easier to discover.

Start with the setup and workspace commands in [README.md](README.md).

## Before you contribute

Cataquí Mobile is **source-available**, not open source as defined by the Open
Source Initiative. The [PolyForm Shield License 1.0.0](LICENSE) lets you inspect,
modify, and share the software for permitted purposes, but it does not permit
using it to provide a competing product. A product may compete even when it is
free.

The license covers Cataquí-authored material only. Do not submit code, assets,
translations, or other material unless you have the right to license it.

This inbound-equals-outbound policy gives Ventairy Inc. the same license to a

submitting it.

## Submit a change

1. Create a focused branch from `main`.
2. Make the smallest change that fully solves the issue.
3. Run the relevant workspace formatting, analysis, and tests from the
   repository root.
4. Open a pull request and complete every item in the pull request template.

## Third-party material

Identify third-party material in the pull request and preserve its copyright,
license, and notice files. Do not copy code from a project with unclear terms
or from a license incompatible with Cataquí's distribution model.

Maintainers may ask for provenance or reject a contribution when its ownership
or licensing is unclear.
